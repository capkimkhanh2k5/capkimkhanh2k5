## Projects

### JOBIO — AI-Powered Recruitment Platform

> Full-stack recruitment platform with AI-driven CV parsing and job recommendation.

- Django REST APIs + React/TypeScript frontend + PostgreSQL
- Async PDF-to-structured-CV pipeline: PyMuPDF, OCR fallback, Groq LLM, Pydantic validation
- Hybrid job recommendation: BAAI/bge-m3 embeddings, pgvector cosine search, score breakdowns
- Background processing: Celery, Redis locking, retry handling, moderation checks
- CI/CD: GitHub Actions → Docker → GHCR → GCP VM deployment with health checks and rollback

**Stack:** `Python` `Django REST` `Celery` `Redis` `pgvector` `Groq` `React` `Docker Compose` `GitHub Actions`

### RagDraftingAI — Vietnamese Legal RAG Drafting Assistant

> Hybrid RAG system for retrieving Vietnamese legal context and drafting administrative documents.

- BM25 keyword search + E5 dense embeddings + ChromaDB vector retrieval + reciprocal rank fusion + BGE cross-encoder reranking
- Legal document ingestion: metadata extraction, article-aware chunking (400-word / 50-word overlap)
- Groq-hosted Llama models with structured prompts for JSON → DOCX generation
- FastAPI services for legal QA, document drafting, streaming responses

**Stack:** `Python` `FastAPI` `ChromaDB` `BM25` `SentenceTransformers` `Groq` `PostgreSQL` `React` `Docker Compose`

[![Repo](https://img.shields.io/badge/GitHub-RagDraftingAI-181717?style=flat&logo=github)](https://github.com/capkimkhanh2k5/RagDraftingAI)
